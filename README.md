# MediTrack 🩺

A modern healthcare management platform designed to streamline **patient records, clinical workflows, prescriptions, and doctor–patient interactions**.

## ✨ Features

* 👨‍⚕️ Doctor & Admin dashboards
* 🧑‍🤝‍🧑 Patient management
* 🎙️ Voice-to-text clinical notes
* 🤖 AI-assisted treatment draft generation
* 💊 Prescription & medical record management
* 📱 Responsive web interface
* 🔐 Authentication & secure API integration
* 📊 Centralized healthcare data management

## 🏗️ Architecture

```text
MediTrack
├── admin       # Admin dashboard
├── backend     # API & server-side logic
└── frontend    # User-facing application
````

## 🛠️ Tech Stack

**Frontend:** TypeScript, React, modern UI/UX
**Backend:** Node.js, REST APIs
**AI:** Speech-to-Text & AI-assisted clinical workflows
**Authentication:** JWT-based authentication
**Database:** Application-specific persistent data layer

## 🚀 Getting Started

```bash
git clone https://github.com/Coderzer69/MediTrack-2026.git
cd MediTrack-2026
```

Install dependencies inside the required applications:

```bash
cd frontend
npm install
npm run dev
```

Repeat for `backend` and `admin` according to their respective configuration.

## 🔐 Environment Variables

Create `.env` files for the required services and add your API keys, database credentials, JWT secrets, and other environment-specific configuration.

**Never commit secrets or `.env` files to GitHub.**
